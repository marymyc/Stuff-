# Animated Shorts Template

**سكريبت يدخل ← فيديو قصير متحرك يخرج.** قالب جاهز لأي نموذج ذكاء اصطناعي (Claude Code، Codex، Gemini CLI، Cursor…):
تعطيه السكريبت + هذا المستودع، فيكمل الباقي ويُخرج فيديو عمودي 55–70 ثانية بأسلوب
"شخصيات كرتون ثنائية الأبعاد داخل عالم ثلاثي الأبعاد ملوّن"، مع تعليق صوتي ومؤثرات وموسيقى مولّدة بالكود.
كل شيء يُرندر على جهازك (three.js + Remotion)، بدون أي مولّد فيديو بالذكاء الاصطناعي.

> Script in → vertical animated short out. Works with any coding agent: it reads `AGENTS.md` and runs the pipeline.

## الاستخدام في 3 خطوات
1. **التجهيز (مرة واحدة):** ثبّت Node 18+ و Python 3.9+ و ffmpeg، ثم شغّل `setup.sh` (ماك/لينكس) أو `setup.ps1` (ويندوز).
   - أضف مجسّمات Kenney المجانية: `public/bridge/kenney/README.md`.
   - اختر محرك الصوت في `.env`: `elevenlabs` (الافتراضي، يحتاج مفتاح API يُضبط مرة واحدة)، أو `openai` (مفتاح API)، أو `manual` (تسجيل الصوت)، أو `kokoro` (مجاني محلياً لكنه يحتاج تثبيتاً إضافياً وتنزيل النموذج أول مرة).
2. **افتح المجلد في النموذج** والصق البرومبت الموجود في `PROMPT.md` مع السكريبت.
3. **استلم النتيجة:** `out/<name>/final.mp4` (2K عمودي 1440×2560).

إذا توقف النموذج أو انتهت جلسته: كل خطوة محفوظة في `projects/<name>/STATUS.md`، وأي نموذج آخر يكمل من نفس النقطة.

## ما الذي في المستودع
| المسار | المحتوى |
|---|---|
| `AGENTS.md` | التعليمات الكاملة لأي نموذج (المصدر الوحيد). `CLAUDE.md` و`GEMINI.md` و`.cursorrules` و`.github/copilot-instructions.md` تحيل إليه |
| `PROMPT.md` | البرومبت الجاهز للنسخ (عربي/إنجليزي) |
| `SCRIPT_TEMPLATE.md` | شكل السكريبت: الحقائق + التعليق الصوتي + ملاحظات بصرية |
| `src/videos/bridge/` | الكود الكامل للمثال المجرّب (العالم، الشخصيات، الحبر، عمق الميدان، تدرج الألوان، الكاميرا) |
| `projects/bridge/` | سكريبت المثال + كود الصوت (مؤثرات، موسيقى مارش، المكساج) |
| `tools/` | كل أدوات الخط الإنتاجي (الجدول تحت) |
| `references/` | تقارير الأسلوب المقاسة + إطارات مرجعية للمقارنة |
| `docs/PIPELINE_DETAILS.md` | الدليل الأصلي الكامل: كل القيم والقواعد والمشاكل وحلولها |

## الأدوات
| الأداة | الوظيفة |
|---|---|
| `tools/check_env.py` | يفحص كل المتطلبات ويقول بالضبط ما الناقص |
| `tools/new_short.py` | ينشئ فيديو جديد من القالب ويسجّله ويجهّز ملف المتابعة |
| `tools/voice_tts.py` | يحوّل السكريبت إلى صوت (ElevenLabs / OpenAI / Kokoro مجاني / تسجيل يدوي) |
| `tools/words_align.py` | يستخرج توقيت كل كلمة بـ Whisper (كل الصورة والصوت متزامنان معه) |
| `tools/stills.mjs` | يرندر لقطات ثابتة لفحص الشكل |
| `tools/sbs_sheet.py` | يضع لقطاتك بجانب المراجع للمقارنة |
| `tools/sandbox.py` | نسخ منفصلة لتحسين الشكل بالتوازي ثم دمجها |
| `tools/render.py` | الرندر النهائي 2K + دمج الصوت + فحص الجودة |
| `tools/short_qa.py` | فحص كل إطار: أسود/أبيض/متجمد/قفزات + مستوى الصوت |
| `tools/shots.py` | يستخرج خريطة اللقطات للفحص |
| `tools/import_kenney.py` | ينسخ مجسّمات Kenney المطلوبة إلى مكانها |

## متطلبات وحدود مهمة
- **النموذج يجب أن يكون "وكيل برمجة"** يقرأ نسخة محلية من المستودع ويعدّل الملفات ويشغّل الأوامر على جهازك. نموذج دردشة عادي لا يستطيع الوصول إلى ملفات GitHub أو تشغيل الرندر وحده؛ تحتاج تنزيل المستودع وفتحه في Claude Code أو Codex أو Gemini CLI أو Cursor أو وكيل مشابه.
- كل قصة جديدة تحتاج إعادة كتابة `story.ts` و`build.ts` و`cast.ts` وملفات الصوت؛ الجودة تعتمد على قوة النموذج في البرمجة.
- كرت شاشة يُنصح به بشدة. الرندر النهائي ~10 دقائق لفيديو 67 ثانية.
- الإطارات في `references/` للدراسة فقط؛ لا تنشرها. إن كان المستودع عاماً فالأفضل حذف `references/frames` و`references/sheets`.
