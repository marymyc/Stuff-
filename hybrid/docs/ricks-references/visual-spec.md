# Visual Spec: Stage-1 Blocking + Stage-2 Blender 5.2 Final Production

Stage-1 browser WebGL (`Remotion + Three.js` with `InkPass`) is strictly a **fast blocking & storyboard inspection stage**, while `scripts/export-cards.mjs` exports batched transparent 2D actor/FX sprites via Canvas2D. **Final shipped Shorts MUST be rendered in Stage-2 Blender 5.2 GPU** (`scripts/blender_render.py`) unless explicitly asked for fast Stage-1 blocking output, because authentic `@RicksClips3000` look combines **outline-FREE clean PBR 3D worlds**, rich architectural sets across **10-14 locations**, animated 3D props, stylized cerulean/golden/night sky gradients, soft cast shadows, thin-lens DOF, `Fog Glow`, and **elastic rubber-hose `30fps on ones` character cards** with crisp bold ink contours.

## 1. Stage-1 Post-Processing Stack (`ShortComposition.tsx`) - Blocking & Preview Only
Preserve this EffectComposer order during rapid Stage-1 blocking:
1. `RenderPass(scene, camera)`
2. `InkPass(scene, camera)`: View-space normal + depth outlines on world geometry (`layer 0`).
3. `EffectPass(camera, lens.pre)`: Depth circle-of-confusion pre-pass.
4. `EffectPass(camera, lens.main, bloom, tone, grade, grain)`: Bokeh DOF (`cInf=0..10px`), HDR bloom (`1.0`, `0.40..0.55`), `ToneMappingMode.NEUTRAL`, `GradeEffect` (`GRADE_DAY2`/`GRADE_GOLDEN2`/`GRADE_INTERIOR`/`night`), micro-grain (`<= 0.006`).

## 2. Snap-and-Hold Character Sprite & Acting Standards (`src/engine/toon.ts` v5.1)
- **`NOINK` Layer (`NOINK = 3` in `ink.ts`):** All 2D character cards (`Actor`), FX (`Fx`), `DustField`, `LightShafts`, painted clouds, sun disc/halo, and unlit `MeshBasicMaterial` signage MUST sit on layer `NOINK`, with `cam.layers.enable(NOINK)`.
- **v5.1 Authentic `@RicksClips3000` Proportions, Headroom & Snap-and-Hold Motion (`toon.ts` + `cards.ts`):**
  - Default `SKIN = "#fcfdfe"`, `INK = "#1f1526"`, adult `BUILD` (`3.48 HH`: `a=120, hh=1.08, torso=1.18, legs=1.22`, `0.94 H/W` horizontal bean head, tapered `inkRing(k=0.34)`, vertical capsule torso with inner `rimLight` highlight, visible `~0.05W` noodle arms + articulated elbows/hands, bowed legs, `SH_SKIN = [0.76, 0.79, 0.88]` cool crescent shadow).
  - **Top-Hat-Safe Card Box & 3-Phase `jumpState`:** Always export actor bitmaps with `width: 900, height: 1680, designW: 600, designH: 1120, soleY: 1080` and `heightM: 2.15` (`cards.ts`) so high-crown hats (`tophat`, `cap`, `officer`) maintain permanent headroom at `y > 0`. Drive leaps in 3D `pos[1]` via `jumpState(f, tTakeoff, tLand, peakM)` (6f `knees` bend anticipation + slight crouch squash -> parabolic 3D `pos[1]` lift + tucked airborne `hop` knees -> 7f landing absorb), rather than shoving `hop` alone near the PNG top edge.
  - **Grounded Runs & Crisp Pose Holds (No Continuous Wobble):** `"run"` keeps a planted stride curve (micro `runHop` only near max extension `>= 0.90`) so characters never float across floors. Reserve `squash` (`scaleY = squash`, `scaleX = 1 / sqrt(squash)`), `inflate`, `spineCurve`, `springBounce()`, and `headOff`/`headSquash` for crisp 6-12f transition/impact accents and snappy holds rather than continuous rubbery sine wobbles on idle beats.
  - **Articulated `ArmPose` & Facing-Aligned Hand Props (`sSide`):** Drive `"hang" | "hip" | "point" | "raise" | "think" | "shrug" | "wave"` with smooth `armK` (`0..1`). Single-handed props (`contract`, `cash`, `stamp`, `briefcase`, `wallet`, `clipboard`, `hammer`) render once inside the hand; active `"stamp"` slams route through a dedicated `pKind === "stamp"` block ahead of `armR` waves using `facing` (`sSide = facing < 0 ? -1 : 1`) so the arm reaches directly down onto the desk with the rubber stamp gripped in-fist (never leave a hovering 3D stamp cube over bare hands).
  - **30fps `on ones` Living Sequences (`cards.ts`):** Export continuous `addLivingSeq` streams with `pitchDeg` / `yawDeg` 3D card tilting, `0.7-1.4s` shaped 4-frame `blinkValueAt` blinks covering swaps, and animated FX (`fxSparkles`, `fxBurst`, `fxCreak`, `fxHatSteam`, `fxIdeaBulb`, `fxPhoneRing`). Keep **`mouthOpen: "auto"` (static emotion-matched mouth per beat)** for third-person narration.

## 3. Stage-2 Blender 5.2 GPU Render Spec (`scripts/export-cards.mjs` + `scripts/blender_render.py`)
Authentic `@RicksClips3000` visual polish: **outline-FREE clean PBR 3D worlds**, 10-14 curated zones, multi-part beveled hero props & vehicles, animated 3D world props, real cast shadows from both props and 2D character cards (`emit_mix = 0.50`), soft thin-lens DOF, `Fog Glow`, and synchronized `camPath` + per-frame `light` changes.
- **Step 3A - Batched 2D Card, Lighting & Camera Export (`scripts/export-cards.mjs`):** Renders PNG cards in Chromium batches (`BATCH = 20` per `page.evaluate`) and embeds per-frame `camPath` (`pos`, `look`, `fov`, `roll`, `cInf`, `focus`, `shot`, `light`, `flash`) supporting dynamic `story.lightAt(f)` mid-shot lighting turns! Keep card IDs free of Windows-illegal characters (`|`, `:`, `*`, `?`, `/`, `\`).
- **Step 3B - Multi-Zone 3D World, Multi-Part `bmesh` Vehicles/Props & Outline Policy (`scripts/blender_render.py` + `scripts/blender_scene.py`):**
  - **Outline-FREE Default (`--ink` opt-in only):** Matching real `@RicksClips3000` videos, Blender 5.2 renders clean PBR 3D architecture, interiors, vehicles, and props **without black outlines** by default (`#1f1526` bold ink lines belong on 2D cards!). Pass `--ink` only if testing an optional `WorldInkHullGN` Inverted-Hull pass. Never use Blender GPv3 `LINEART` over alpha cards (draws lines through foreground characters).
  - **Multi-Part `bmesh` Props & Open-Spoked Rotating Wheels:** Never ship trains, cars, tracks, or hero desk props built from crude solid disc wheels and raw boxes. Construct annular open-spoked wheels (`bmesh` steel tire + flange + inner painted rim + radially arrayed open spokes + counterweight + crankpin) parented to **unrotated XZ Empty pivots** (`matrix_parent_inverse = pivot.matrix_world.inverted()`) so animating `pivot.rotation_euler.y` spins spokes vertically and syncs smoothly with coupling/piston rods! Lay beveled trapezoidal ballast + wooden sleepers + true I-beam steel rails with tie-plates; sculpt multi-part hero props (`add_rotary_phone` dial/cradle/handset, saucer + handled mugs, stamp pads + revealed ink seals) cleanly anchored to static surfaces.
  - **Multi-Zone Y Staging (`update_frame`):** Place each distinct set at separated Blender Y offsets (`0, 150, 300, 450, ...`), toggle `hide_render` per active frame range so only 1 zone renders at a time (~0.5-0.9s/frame in EEVEE `--samples 6`), keep foreground poles/streetlamps clear of moving vehicle camera corridors, and animate 3D props inside `update_frame` (rushing exterior scenery trees/poles past windows, spinning wheels/rods, dynamic bulb/siren lights). Remember 9:16 horizontal frustum width `horiz = 2 * dist * tan(vfov/2) * 9/16`: keep multi-actor tables and tall airborne leaps cleanly inside horizontal and vertical safety margins!
  - **Stylized Sky Ramp & Lighting (`apply_world_sky`):** Blend `ShaderNodeValToRGB` (`day` `#76bcff -> #2d82f2 -> #0d52d4`, `golden` `#ffaa48 -> #c86878 -> #4b3e7c`, `interior`, `night`) over `ShaderNodeTexSky`, orient cards upright (`orient_card_upright` with `rotDeg`, `pitchDeg`, `yawDeg`, `scaleX`, `scaleY`, `jitter`), and keep interior/night zones properly key-lit so sets read clearly without crushing to mud.
- **Step 3C - Pure White Bold Caption & Audio Composite (`scripts/composite_stage2.mjs`):** Converts `public/audio/words.json` into crisp vector `.ass` captions (`Arial Black`, `98px` in `1080x1920`, pure `#FFFFFF` with bold `10px` `#000000` outline at `MarginV=530`, subtle pop-in; `--yellow-emphasis` opt-in if yellow keywords are requested) and muxes `-15.0 LUFS` `public/audio/mix.wav` into `out/final.mp4`.
