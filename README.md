# Stuff- — مصنع فيديوهات قصيرة

مشروع معياري لإنتاج فيديوهات تعليمية/تاريخية إنجليزية عمودية بنسبة 9:16 ومدتها 60–70 ثانية. يأخذ السكريبت فقط، ثم يخطط المشاهد واللقطات، ويبني بيئات Blender كرتونية مبسطة، ويولّد التعليق الصوتي عبر Chatterbox مع مرجع صوتي يقدمه المستخدم، ويزامن الترجمة والمؤثرات، ثم يجمع MP4 عبر FFmpeg.

## التشغيل

استخدم Google Colab وافتح `notebooks/colab_render.ipynb`. ثبّت البيئة، أضف WAV مرخصًا خاصًا إلى Google Drive، ثم ضع السكريبت الإنجليزي في خلية الإدخال وشغّل خلية الرندر الأخيرة. لا ترفع المرجع الصوتي أو أي مفاتيح إلى GitHub.

## التحقق

اختبارات الوحدة وعمليات Blender وChatterbox ومزج الترجمة/الصوت تُنفذ عبر GitHub Actions. لن أعتبر الرندر ناجحًا قبل ظهور نتائج التشغيل الفعلية.

## ملاحظة

المشاهد والشخصيات في هذه النسخة مبسطة وإجرائية؛ جودة الرسوم قابلة للتطوير بإضافة أصول مرخصة. راجع `docs/validation-report.md` لنتائج الاختبارات بعد تشغيلها.
